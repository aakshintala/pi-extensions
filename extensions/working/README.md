# working

Pi's existing editor border shows the turn's activity without adding another row. While the model is active, it shows `Thinking · 12s`; while tools run, it shows `Running tool · 12s`. A subtle accent travels across the label. The elapsed time starts when the agent run begins and updates each second. The label switches only when tool activity starts or ends.

Pi's own spinner remains in place. The label resets after the run or session ends. Tool summaries use static marks, so there is only one animated working indicator.

None.
